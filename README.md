# Mousse Delícia — versão personalizada
Site responsivo criado a partir da proposta do projeto original, com identidade Blush de Mirtilo.

Páginas:
- index.html — página principal, cardápio, promoções, avaliações e encomenda.
- avaliacao.html — área de avaliações com estrelas e seleção de foto.

Funcionalidades:
- filtros de cardápio: saudável, doce, bebidas e combos;
- carrinho/pedido salvo no navegador (localStorage);
- formulário de encomenda;
- avaliações salvas no navegador;
- seleção de foto para avaliação (a interface permite selecionar a foto; para publicar e armazenar a imagem de verdade, seria necessário backend/storage).
